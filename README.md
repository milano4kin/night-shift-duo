# DREAD SHIFT v8.9.9 — restored runtime

Актуальная ветка восстановления DREAD SHIFT поверх v8.9.9.x.

Сборка сохраняет текущие исправления v8.9.9.1–v8.9.9.4 и последним слоем восстанавливает потерянные системы лобби и регрессии: INDEX/CODES, промокоды, резервную HTTP-регистрацию/авторизацию, 30-секундную подготовку, плавное следование питомца, накопительные награды за волны, просмотр пароля, уровень генератора и исправления старых gameplay-регрессий.

Промокоды:
- `Welcome`: 300 серебра, 25 золота, 1 жетон ящика.
- `TEST`: 150 серебра, 10 золота.

## Render
Build command: `bash build-render.sh`
Start command: `bash start-render.sh`

## Локальный запуск
```bash
npm ci
npm start
```

## Проверка
```bash
npm run patch:runtime
npm test
```

Production build дополнительно минифицирует браузерный клиент через `scripts/protect_client.js`.
