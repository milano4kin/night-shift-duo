# DREAD SHIFT v8.1

Текущая исходная сборка DREAD SHIFT v8.1.

В v8.1 переработаны постоянные улучшения, награды за пройденные волны, плавность питомцев, магнитное соединение стен, интерфейс мастерской генератора и открытие ящиков.

## Render
Build command: `bash build-render.sh`
Start command: `bash start-render.sh`

## Локальный запуск
`npm ci`
`npm start`
