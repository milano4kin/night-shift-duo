# DREAD SHIFT v8.4

Текущая исходная сборка DREAD SHIFT v8.4.

В v8.4 подготовка перед каждой волной увеличена до 30 секунд, HUD этажа теперь явно показывает диапазон из пяти волн, обновлены награды кодов Welcome и TEST, колокольчик уведомлений оставлен только в лобби, дубликаты питомцев больше не создают уведомление «Новый питомец», а сетевое движение переработано для более быстрого согласования позиции без эффекта скольжения.

## Render
Build command: `bash build-render.sh`
Start command: `bash start-render.sh`

## Локальный запуск
`npm ci`
`npm start`
