# DREAD SHIFT v8.3

Текущая исходная сборка DREAD SHIFT v8.3.

В v8.3 усилена надёжность регистрации и входа: аккаунты создаются через HTTPS с автоматическим восстановлением игрового WebSocket. Также переработаны шипы как проходные ловушки с ресурсом контактов, исправлена точка выстрела пистолета, позиция SHOP/UPGRADE у генератора и расположение центра уведомлений.

## Render
Build command: `bash build-render.sh`
Start command: `bash start-render.sh`

## Локальный запуск
`npm ci`
`npm start`
