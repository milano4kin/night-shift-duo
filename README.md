# DREAD SHIFT v8.5

Текущая исходная сборка DREAD SHIFT v8.5.

В v8.5 движение игрока переработано архитектурно: локальный персонаж больше не тянется к устаревшим серверным снимкам во время обычного движения, камера следует за локальной прогнозируемой позицией без инерционного хвоста, изменения клавиш движения отправляются серверу сразу и дополнительно с частотой 30 Гц, серверные снимки отправляются с частотой 20 Гц и содержат скорость игрока для плавного отображения напарника. Маленький числовой индикатор у портрета теперь явно подписан как уровень персонажа текущего забега.

## Render
Build command: `bash build-render.sh`
Start command: `bash start-render.sh`

## Локальный запуск
`npm ci`
`npm start`
