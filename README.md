# DREAD SHIFT v8.5.3

Текущая исходная сборка DREAD SHIFT v8.5.3.

В v8.5.1 локальный персонаж мгновенно реагирует на нажатие и отпускание WASD, камера следует за локальной прогнозируемой позицией без инерционного хвоста, а серверные коррекции применяются только при заметном расхождении. Напарник интерполируется плавно с учётом фактической серверной скорости. Стабильная частота серверных снимков v8.4 сохранена. Индикатор у портрета явно подписан как уровень персонажа текущего забега.

В v8.5.2 названия всех оружий аккуратно размещаются в двух строках внутри слота. Production-админка доступна только авторизованному аккаунту `cattencel`; право проверяется сервером для каждого запроса.

В v8.5.3 строка текущего оружия и боезапаса поднята над увеличенной панелью быстрого доступа. Постоянные улучшения теперь проверяют, показывают и списывают серебро вместо золота.

## Render
Build command: `bash build-render.sh`
Start command: `bash start-render.sh`

## Локальный запуск
`npm ci`
`npm start`
